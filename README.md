# Job Automation Bot

Automation workflow designed to streamline vacancy discovery and application tracking.

## Problem

Manual job searching and vacancy monitoring can be time-consuming and difficult to manage consistently.

## Solution

Developed an automation workflow that monitors vacancies, collects relevant information, and supports a structured application process.

## Key Features

- Automated vacancy monitoring
- Vacancy data collection
- Application tracking support
- Structured workflow automation
- Reduced manual effort

## Tools Used

- Python
- Playwright
- Google Cloud Platform

## Outcome

Built a working automation solution to streamline job search operations and improve efficiency in vacancy monitoring and tracking.
